# Cozy Corner

A tiny always-on-top pixel room with a little virtual self inside. Drag it around the desktop, watch it idle / sit / walk, and hide or quit from the tray or a right-click menu.

It can also drive the YouTube player you already host at [thinkcolorful.org/ytplayer](https://thinkcolorful.org/ytplayer/): Cozy Corner opens that page in a hidden WebView and sends Play / Pause / Stop into `window.youtubePlayer`. Paste a URL in the player window first, then control it from the overlay.

## Requirements

- Node.js 18+
- [Rust](https://www.rust-lang.org/tools/install) (stable)
- Windows: [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (workload **Desktop development with C++**)
- WebView2 (already on current Windows 10/11)

On Windows, `link.exe` must be on PATH. The simplest way is **x64 Native Tools Command Prompt for VS 2022**, or from PowerShell:

```powershell
cmd /c "call `"C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat`" && npm run tauri dev"
```

## Run

```bash
npm install
npm run assets
npm run tauri dev
```

The widget is 256×192 CSS pixels (64×48 art at 4×, integer scale, `image-rendering: pixelated`). It stays above other windows, has no title bar, and skips the taskbar. Use the tray icon for **Show**, **Hide**, **YouTube Player**, **Play / Pause**, **Stop music**, and **Quit**. Right-click the room for the same actions. Click the desk on the right to play/pause. Closing a window hides it instead of exiting.

### Music (your ytplayer)

1. Right-click the room → **YouTube Player** (or use the tray).
2. Paste a YouTube URL and press Play once in that window so the IFrame API can start.
3. After that, Play / Pause / Stop from the overlay, tray, or desk hotspot. Audio keeps going while the player window is hidden.

The player is still your site; this app does not re-implement YouTube. It only loads that page and calls `playMusic()` / `stopMusic()`.

Release zip (Windows):

```bash
npm run tauri build
```

The NSIS installer and exe land under `src-tauri/target/release/bundle/nsis/`.

## macOS flags (same codebase, test on a Mac)

These are already set so a Mac build can be tried without extra product work:

- `transparent`, `decorations: false`, `alwaysOnTop`, `shadow: false`
- `visibleOnAllWorkspaces` (Spaces / Mission Control)
- `macOSPrivateApi` plus the `macos-private-api` Cargo feature (needed for some always-on-top + transparent combinations)
- `skipTaskbar` (hides the Dock tile; control the app from the tray)
- At startup the Rust side also calls `set_visible_on_all_workspaces(true)` and `set_shadow(false)`

When you have a Mac:

1. Install Xcode Command Line Tools and Rust.
2. Add an `.icns` with `npx tauri icon src-tauri/icons/icon.png` (Windows builds do not need it).
3. Set `"targets": ["nsis", "dmg"]` in `src-tauri/tauri.conf.json` if you want a dmg.
4. Run `npm run tauri dev` and check: transparent corners, always-on-top over other apps, drag, tray Show/Hide, no window shadow, survives Space switches.
5. If the window is opaque or not topmost, that is the usual 1–2 hour macOS fight (window level / private API), not a missing feature in the TS layer.

Do not block a Windows build on notarization or a signed `.app`.

## Layout

- `src-tauri/tauri.conf.json` — overlay window + bundle icons
- `src-tauri/src/lib.rs` — tray menu, hide-on-close, quit
- `src/main.ts` — game loop
- `src/render.ts` — integer-scale canvas
- `src/self.ts` — idle / sit / walk
- `src/cat.ts` — background pet (idle / loaf / walk / sleep)
- `src/assets/room.png`, `src/assets/self.png`, and `src/assets/cat.png` — generated by `npm run assets`
